3. EVALUACIÓN Y TRATAMIENTO DE ALERTAS REGISTRADAS
   - [Medium (High)] Content Security Policy (CSP) Header Not Set (Plugin 10038): 3 instancias
     * GET https://qa.quickpatch.internal
     * GET https://qa.quickpatch.internal/robots.txt
     * GET https://qa.quickpatch.internal/sitemap.xml
     * Tratamiento técnico: La regla 10038 está formalmente catalogada como IGNORE en zap-baseline.conf.
       CSP restringe ejecución de scripts HTML embebidos en navegadores. Los servicios de backend
       de QUICKPATCH son APIs REST sin estado que sirven payloads application/json autenticados
       por Bearer JWT, sin páginas web renderizadas desde el Gateway.
   - [Low (High)] Strict-Transport-Security Header Not Set (Plugin 10035): 3 instancias
     * GET https://qa.quickpatch.internal
     * GET https://qa.quickpatch.internal/robots.txt
     * GET https://qa.quickpatch.internal/sitemap.xml
     * Tratamiento técnico: En la raíz '/' de Nginx Ingress no existe index HTML (retorna 403 Forbidden).
       La cabecera HSTS se emite en respuestas 2xx/3xx; se recomienda añadir el flag 'always' en Nginx
       para el despliegue final en Producción. Impacto en API: Nulo (solo se acepta HTTPS con TLS 1.2 y 1.3).
